# Por onde começar

Especificar o PRD-02 (invólucro macOS: projeto Xcode `Widget12c`, NSPanel, WKWebView, esquema `hp12c-app://`, BridgeController e StateStore) no fluxo Clavix, e executá-lo. Pontos herdados do PRD-01: o comando nativo `copy` sem gesto do usuário, a preferência de som do upstream gravada no localStorage, e a etapa de build que precisa do motor baixado. DEC-009 (atalho global) bloqueia só o PRD-03.
